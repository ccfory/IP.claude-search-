## 2026-10-25：三种玩法融合为「零点夜班」

现在 `index.html` 默认进入融合夜班。三位访客的聊天、档案和身份互换在同一张工位上连续进行：

1. 向当前访客提问，调用原有上下文对话；询问经历或本人资料会调出同一人的档案原件。可夹起两句发言进行交叉质询。
2. 打开原件，选定最多两份依据。ECHO 的自动摘要、聊天旁证与剧情日志都有明确标记，不能替代有效原件。
3. 使用当前选中的首份材料进入三轮换位盘问，扮演当前访客。盘问会引用他的已公开发言和你选中的材料，接受错误前提会累积疑点。

5. 三份案件共用得分、改写日志、存档和结局；模拟表现影响得分与日志恢复，但不会替代原件的判断效力。

融合剧情使用原档案 01、07、06，分别涉及出口与本人位置、旧地址与设备设置、材料不足时保留未知。无倒计时。数据源固定为虚构历史档案，不使用玩家实际位置或当前日期做判断。新模式目前使用中文与本地规则对话，无需在线模型密钥。

## 独立 IP 判断（自由玩法）

扮演 Claude，在三夜九局里找出伪装的中国用户。12 个中英文手写角色按难度分层，每局随机抽取九位，每夜同时包含目标与反转角色。

- 支持自由输入问题，也可从晚饭、工作、游戏与本人资料四个话题中选三个；每人另有两次不扣分的上下文追问。
- 对方会撤回、改口、记住你先前问过的内容；每个角色有自己的反驳和最后一句话。
- 点选两条发言，点击「指出破绽」；每人只有一次质询机会。命中角色的关键组合会触发承认或合理反驳。
- `D` 封号、`A` 放行；`1 / 2 / 3 / 4` 选择话题；Esc 暂停。至少聊一轮后才能判断。
- 正确 +100，命中质询 +20，连对最多 +30；每问 −5。误封 −80、漏判或超时 −50，三次失误结束。
- 从容模式不计时；限时模式每夜 60 / 50 / 40 秒。阅读对话框、后台与对方输入时停表。
- 先看最后一句话，再揭晓隐藏身份、伪装流派与关键反转；结算可复制本局战报。
- 提供独立免费练习、中英文切换、自动存档与继续；顶部「切换玩法」可回到原版档案，两种玩法的存档独立。

这是剧情预设身份的虚构同人梗游戏，不检测真实 IP，不代表现实服务的国籍判定或封号规则。

## 对话机制

角色会结合已公开发言回应“刚才那句”、资料持有人、前后说法与重复问题；不明确或包含多个主题时会先澄清。原始问题和回复会随存档保存，中英文切换不改写既有记录。

12 位角色拥有各自的封号、退款、修代码、记忆与语言接梗；重复追问会换一种反应，被质询时也会依角色性格嘴硬、补救或反问。

对白参考了社区里的紧张自嘲、主动“自曝”和反向期待封号等调侃，均为原创改写；社区帖子只是趣闻素材，不作为真实封号规则：[Linux.do 自曝讨论](https://linux.do/t/topic/3046781)、[Linux.do 反向期待讨论](https://linux.do/t/topic/2973490)、[V2EX 讨论](https://www.v2ex.com/t/1247943)。

当前为本地规则与上下文对话，范围限于游戏剧情，未接入在线大模型；不需要 API 密钥。新话题每次 −5，两次额外追问及澄清不扣分。

## 原版档案新手指引

- 首次打开会显示五步互动练习：认识工位、调查、选依据、盖章、完成。
- 使用独立的虚构练习档案，不计时、不扣分，不修改正式存档；误选会解释原因并允许重试。
- 可随时跳过；完成或跳过后，本浏览器不再自动弹出。存储不可用时仍可正常练习与跳过。
- 顶部「新手指引」和模式选择页都可重新打开；关闭或按 Esc 返回原位置。
- 支持中英文切换和手机；游戏中打开指引时，正式倒计时暂停。

## 原版档案操作

- `1 / 2 / 3`：问询情况、查接入、核验凭证。
- 选择 1–2 项材料后，`A / D / S`：继续服务、限制访问、人工复核。
- 空格：显示完整对话；Esc：暂停。
- 每项调查扣 5 分；正确 +80，有据 +20，连对额外奖励；四次失误结束。

## 审核规则与来源

独立同人推理游戏，与 Anthropic 无关。全部人物、凭证、账号记录和审核流程均为虚构简化，不检测真实 IP，也不声称模拟未公开的封号算法。

地区资格、账号共享转售、未经许可的个人服务自动化、反复违规及申诉需要结合有效材料判断；正式 API 另有适用条款。中文、国籍、时区、单次换 IP、VPN 标签、高用量或一次模型拒答均不能单独定案。游戏中的“限制访问”不等于永久封号。
